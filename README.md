 # SoIT RGPV College Website

## Project Overview
This project is a multi-page college website for the School of Information Technology (SoIT), Rajiv Gandhi Proudyogiki Vishwavidyalaya (RGPV), Bhopal.

The website provides information about the institution, academic programs, faculty, student achievements and other useful details.

## Technologies Used
- HTML5
- Semantic HTML
- HTML Forms and Tables
- Accessibility Attributes

## Website Pages
1. Home – Introduction to SoIT RGPV.
2. About – Information about the institution.
3. Departments – Research areas.
4. Courses – Academic programs.
5. Faculty – Faculty information.
6. Achievements – Student achievements and projects.
7. Timetable – Sample weekly timetable and marks table.
8. Contact – Contact information and contact form.
9. Registration – Student registration demonstration form.
10. Feedback – Website feedback form.

## Key Features
- Multi-page website with navigation links.
- Semantic HTML structure.
- Accessible forms and tables.
- Metadata and descriptive page titles.
- Organized project structure.
